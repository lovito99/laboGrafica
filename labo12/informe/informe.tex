\section*{Resumen}
Se implementó la curva cúbica del código base y una curva compuesta de dos
segmentos, evaluadas íntegramente por el \textit{vertex shader}. La CPU transfiere
los puntos de control como \textit{uniforms} y duplica el dominio discreto
$t\in[0,1]$ para ambos tramos. La unión satisface continuidad geométrica y
diferencial $C^1$. Además, los extremos $A_0$ y $B_3$ pueden modificarse en los
tres ejes mediante el teclado.

\section{Objetivos}
\begin{itemize}
\item Evaluar en paralelo los polinomios de Bernstein en la GPU.
\item Construir dos segmentos Bézier cúbicos con continuidad $C^1$ estricta.
\item Actualizar puntos de control mediante variables uniformes.
\item implementar interacción tridimensional independiente del framerate.
\end{itemize}

\section{Fundamento matemático del pipeline}
Para cuatro puntos de control, la curva cúbica es
\[
C(t)=(1-t)^3P_0+3(1-t)^2tP_1+3(1-t)t^2P_2+t^3P_3,\quad 0\le t\le1.
\]
La CPU no calcula posiciones de la curva. El VBO contiene solamente 241
escalares equidistantes $t_i=i/240$. El mismo VAO se dibuja dos veces: primero
con los \textit{uniforms} $A_0,\ldots,A_3$ y luego con $B_0,\ldots,B_3$.
Esta ``duplicación'' es modular: se reutiliza el dominio, pero cada llamada
\texttt{glDrawArrays} recibe otro conjunto de puntos de control. Cada invocación
del \textit{vertex shader} evalúa en paralelo un valor de $t$.

\begin{lstlisting}[style=cxx,caption={Evaluación de Bernstein en el vertex shader.}]
float t = aT, u = 1.0 - t;
vec3 pos = (u*u*u)*P0 + (3.0*u*u*t)*P1
         + (3.0*u*t*t)*P2 + (t*t*t)*P3;
gl_Position = projection * view * model * vec4(pos, 1.0);
\end{lstlisting}

\subsection{Ejemplo base implementado}
Se conservaron los tres componentes solicitados en el PDF:
\texttt{curve.vert}, \texttt{curve.frag} y \texttt{mainCurves.cpp}. El ejemplo
base emplea 200 subdivisiones, es decir, 201 muestras incluyendo los extremos.

\begin{lstlisting}[style=cxx,caption={Inicialización semántica del atributo escalar \(t\).}]
constexpr int segments = 200;
std::vector<float> values(segments + 1);
for (int i = 0; i <= segments; ++i)
    values[i] = static_cast<float>(i) / segments;

glBufferData(GL_ARRAY_BUFFER,
             values.size() * sizeof(float),
             values.data(), GL_STATIC_DRAW);
glVertexAttribPointer(0, 1, GL_FLOAT, GL_FALSE,
                      sizeof(float), nullptr);
\end{lstlisting}

\section{Continuidad estricta en la unión}
La continuidad $C^0$ exige que ambos segmentos compartan el punto de unión:
\[
B_0=A_3.
\]
Las derivadas de una Bézier cúbica en sus extremos son
\[
C_A'(1)=3(A_3-A_2),\qquad C_B'(0)=3(B_1-B_0).
\]
Al imponer
\[
B_1=A_3+(A_3-A_2)
\]
se obtiene $B_1-B_0=A_3-A_2$ y, por tanto,
$C_A'(1)=C_B'(0)$. Coinciden posición, dirección y magnitud de la tangente;
la unión es $C^1$, no solo visualmente suave.

\begin{lstlisting}[style=cxx,caption={Restricción recalculada en cada cuadro.}]
const glm::vec3 b0 = a3;
const glm::vec3 b1 = a3 + (a3 - a2);
\end{lstlisting}

\section{Control dinámico 3D}
Las teclas \texttt{1} y \texttt{2} seleccionan $A_0$ o $B_3$. Las flechas
alteran $x$ e $y$, mientras \texttt{W}/\texttt{S} alteran $z$. El desplazamiento
se multiplica por el tiempo entre cuadros para mantener una velocidad uniforme.
Como los puntos se envían en cada iteración, la deformación aparece
inmediatamente sin reconstruir el VBO.

\section{Buenas prácticas}
La creación de ventana, compilación, generación del dominio y dibujo están
modularizados en \texttt{bezierComun.hpp}. Se comprueba la compilación y enlace
de shaders, se eliminan VAO, VBO, programa y ventana, y se usa tamaño semántico
\texttt{sizeof(float)}. El VBO es inmutable porque la interacción solo modifica
\textit{uniforms}.

\section{Conclusiones}
\begin{itemize}
\item Enviar únicamente $t$ reduce el trabajo geométrico de la CPU y aprovecha
la evaluación paralela del pipeline.
\item Las ecuaciones de los puntos de control prueban formalmente la continuidad
$C^1$ en la unión.
\item Los \textit{uniforms} permiten deformación 3D en tiempo real sin transferir
un nuevo conjunto de vértices.
\end{itemize}
